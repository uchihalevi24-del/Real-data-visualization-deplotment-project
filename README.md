📌 Project Overview

This project provides a comprehensive analysis of the Netflix dataset. It uncovers trends in content production, geographical distribution, rating frequencies, and genre popularity over time. The insights are delivered through a fully interactive web application, allowing users to slice and dice the data dynamically.

Key Insights Uncovered

• Content Shift: Longitudinal analysis tracking the aggressive growth of TV shows vs. Movies since 2015.
• Geographical Hotspots: Mapping the primary countries driving content creation.
• Release Patterns: Identifying seasonal trends in when Netflix drops new content.

🛠️ Tech Stack

• Language: Python 3.10+
• Data Manipulation: Pandas, NumPy
• Data Visualization: Plotly Express, Seaborn, Matplotlib
• Web Framework: Streamlit / Dash (Choose one)
• Deployment: GitHub, Streamlit Cloud / Docker / AWS (Choose your platform)

📊 Visualizations Included

• Interactive Choropleth Map: Global distribution of content production.
• Timeline Analysis: Line graphs showing the evolution of added content over the years.
• Content Breakdown: Donut charts illustrating the ratio of Movies to TV Shows.
• Word Clouds \& Bar Charts: Top actors, directors, and genres.
